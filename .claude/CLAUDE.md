## Commands

Use `npm` (not `pnpm`) to run scripts despite the `packageManager` field in package.json:

```bash
npm start          # dev server at http://localhost:4200
npm run build      # production build → dist/
npm test           # unit tests with Vitest
```

No lint script exists; formatting is enforced by Prettier (`.prettierrc`: 100-char width, single quotes, Angular HTML parser).

To run a single test file: `npm test -- --reporter=verbose src/app/path/to/file.spec.ts`

## Architecture

Patternalia is a personal crafts pattern library (knitting, crochet, embroidery). It is an Angular 21 SPA backed entirely by AWS Amplify serverless infrastructure.

### Frontend (`src/`)

Feature-based structure under `src/app/`:

- **`core/`** — singleton services and cross-cutting concerns: `AuthService` (Cognito via Amplify), `authGuard` (route protection), HTTP interceptor (attaches JWT Bearer token to all API requests), and TypeScript model interfaces (`Pattern`, `Category`).
- **`features/`** — lazy-loaded route components: `auth/` (login, register, confirm, forgot-password), `categories/` (CRUD), `patterns/` (list, upload, detail, edit).
- **`shared/`** — reusable UI: `ApiService` (HTTP wrapper), `RavelryService` (proxied Ravelry API calls), plus components like `PdfViewer`, `ConfirmDialog`, `EmptyState`, and the app shell.

All routes are lazy-loaded; root redirects to `/patterns`. Protected routes require `authGuard`.

State is managed entirely with Angular signals — no global store, no RxJS subjects for local state.

UI is built with **Tailwind CSS** + **PrimeNG** (Indigo theme). PDF viewing uses `ngx-extended-pdf-viewer`.

### Backend (`amplify/`)

Infrastructure-as-code via AWS Amplify Gen 2 (CDK under the hood):

| Resource | Purpose |
|----------|---------|
| Cognito User Pool | Email/password auth with email verification |
| S3 bucket | PDF storage — `patterns/{patternId}.pdf`, annotated versions under `annotated/` |
| DynamoDB | `patternalia-patterns` and `patternalia-categories` tables |
| API Gateway + Lambda | REST CRUD API (JWT-protected) |
| Lambda `resize` | Generates thumbnails/previews; **fires on every S3 PUT under `patterns/`** — avoid unnecessary writes to that prefix |
| Secrets Manager | Ravelry API key (Lambda-only access) |

`amplify_outputs.json` (git-ignored) is auto-generated by Amplify and must be present in the project root for the app to start. The `src/environments/` files hold the API Gateway base URL.

### Auth flow

`APP_INITIALIZER` in `app.config.ts` restores the Cognito session on startup. The HTTP interceptor then attaches the token. Components never handle tokens directly — use `AuthService`.
